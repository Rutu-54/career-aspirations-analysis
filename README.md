# Career Aspirations Analysis

## About the Project

This project analyzes Gen-Z career aspirations to identify patterns in career preferences, workplace expectations, and manager aspirations.

## Tools Used

* Microsoft Excel
* Power BI
* Pivot Tables
* Data Cleaning
* Data Visualization

## Work Performed

* Cleaned and organized the dataset.
* Used Pivot Tables to analyze career aspiration data.
* Created visualizations and dashboards in Power BI.
* Identified key trends and insights from the data.

## Project Outcome

The analysis provides insights into Gen-Z career preferences and expectations through interactive visualizations and data-driven findings.
